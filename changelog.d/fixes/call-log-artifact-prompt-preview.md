- **fix(logs):** Oversized call log artifacts now keep a preview of the request/response bodies (first `CALL_LOG_ARTIFACT_PREVIEW_KB`, default 8 KiB, degrading to 2 KiB before falling back to omission) and the real error (up to 4 KiB, UTF-8-safe truncation) instead of replacing them with `[omitted: ...]` markers. The request log detail view no longer renders the size-limit omission marker as a red Error; it shows an amber notice and labels truncated previews with kept vs original size.
